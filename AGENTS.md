# Project Guidance

This project has a React/Vite frontend in `frontend/` and a FastAPI backend in
`backend/`.

- Inspect existing code before editing, and explain significant changes so the
  project owner can learn from them.
- Preserve existing functionality and API contracts unless explicitly asked to
  change them.
- Run relevant tests after code changes: backend tests in `backend/` and the
  frontend lint/build checks in `frontend/`.
- For frontend changes, verify responsive layouts and interactions in a browser
  when possible.
- Never expose secrets or credentials.
- Do not deploy to production or make production changes without explicit
  approval.
